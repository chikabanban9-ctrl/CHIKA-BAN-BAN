# CHIKA BAN BAN 🍹

An interactive, responsive landing page website for CHIKA BAN BAN fruit juice flavors.

## 🚀 Live Preview & Vercel Deployment

This project is fully optimized for **Vercel** zero-config deployment.

### Deploy to Vercel in 1-Click:
1. Go to [Vercel](https://vercel.com).
2. Import this GitHub repository: `https://github.com/chikabanban9-ctrl/CHIKA-BAN-BAN.git`
3. Click **Deploy**. Vercel will automatically detect `index.html` and serve your website instantly!

## 💻 Local Server Setup

To run locally on your laptop and test on mobile:

### Using PowerShell (Built-in Web Server):
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```

### Access Links:
- **Laptop:** `http://localhost:8000`
- **Mobile (Public Tunnel):** `ssh -o StrictHostKeyChecking=no -R 80:localhost:8000 nokey@localhost.run`
